# Raka Fadillah — Creative Developer

An ocean-depth portfolio built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

```sh
bun install
bun run dev
```

The development server runs at `http://localhost:5173` unless the port is already in use.

## Scripts

- `bun run dev` — start the Vite development server
- `bun run build` — create a production build
- `bun run preview` — preview the production build locally
- `bun run lint` — run ESLint

## Deployment

This project is configured for Vercel with Nitro. Import the repository in
Vercel; it will install dependencies with Bun and run `bun run build`.
